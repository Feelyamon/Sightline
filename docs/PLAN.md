# План: из трекера боя в приложение со статистикой

## Зачем

Сейчас приложение живёт один бой и забывает всё при рестарте. Нужно: история боёв в базе,
счётчики как в танках, накопительная статистика по игрокам («с кем чаще играю», «против кого чаще»),
одно окно вместо двух и разделение экрана на союзников и противников.

## Стек

**Electron остаётся.** Логика (`killfeed-parser`, `battle-state`, `wt-client`) уже написана и покрыта
тестами — переезд на Rust означал бы переписать её с нуля ради экономии 130 МБ на диске.
Пользователю Node не нужен: electron-builder вшивает рантайм в `.exe`.

База — SQLite (`better-sqlite3`), файл в `app.getPath('userData')`. Синхронный API здесь плюс:
запись боя происходит одним коротким транзакционным блоком, гонок нет.

## Ограничения, которые надо помнить

1. **Видны только те, кто засветился в кил-фиде.** Полного списка из 32 игроков API не отдаёт.
   Практика: 60–80% команды за бой. В UI это должно быть написано, а не подразумеваться.
2. **Опыта за бой в API нет.** Ни `/state`, ни `/mission.json`, ни `/hudmsg` его не содержат.
   Реально только OCR экрана результатов — отдельная задача, в этот этап не входит.
3. **Пати не определяется напрямую.** «Топ союзники» считается как «был в моей команде N боёв».
   Уточнение по чату отряда (`/gamechat`) — опционально, работает только когда сокомандник пишет.
4. **Класс техники угадывается**, а не берётся из API. Словарь шаблонов + вывод из глагола
   («сбил»/«разбился» = воздух). Неопознанное — в лог, как нераспознанные глаголы.

## Схема БД

```sql
battles(id, started_at, ended_at, map, mode, my_kills, my_deaths, my_vehicles)
players(id, nick UNIQUE, first_seen, last_seen, battles_total)
battle_players(battle_id, player_id, team, kills, deaths, vehicles_json, left_battle)
counters(name PRIMARY KEY, reset_at)   -- session | today | week | month
```

Счётчики — не хранимые числа, а запросы `COUNT(*) FROM battles WHERE started_at > reset_at`.
Поэтому «сбросить» = обновить `reset_at`, а полное удаление истории обнуляет все четыре разом.

## Экраны (одно окно, вкладки)

- **Бой** — живая таблица. Две колонки: слева союзники, справа противники. Иконка класса техники
  перед названием. Статус, текущая машина, история вылетов.
- **Счётчики** — 4 плитки: сессия (с запуска), сегодня, неделя, месяц. У каждой своя кнопка сброса.
- **Игроки** — накопительная таблица: ник, сколько боёв вместе, сколько против, любимая техника,
  последняя встреча. Топ союзников и топ противников (те, кто попадался >5 раз за месяц).
- **Настройки** — ник, поведение окна, управление БД (сбросы с подтверждением, бэкап, размер файла).

## Сбросы

| Кнопка | Что делает |
|---|---|
| Сбросить счётчик (×4) | двигает `reset_at` для одного счётчика, история цела |
| Удалить бой | убирает один бой из истории и пересчитывает агрегаты |
| Очистить всю историю | удаляет `battles` + `battle_players`, обнуляет все счётчики |
| Очистить базу игроков | удаляет `players` целиком |

Опасные — с подтверждением вводом слова и автоматическим бэкапом файла БД рядом.

## Этапы

1. **Ядро**: БД, запись боя по его окончании, одно окно с вкладками, сплит союзники/противники,
   иконки классов. ← этот этап
2. **Статистика**: агрегаты, топы, фильтр «>5 раз за месяц», графики.
3. **Сборка** `.exe` через electron-builder.
4. **Далеко**: свой сервер, общий сбор статистики, OCR результатов боя.
