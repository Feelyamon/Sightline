# Sightline 1.0.3

## Администрирование ушло из программы

- В программе больше нет раздела «Админка». Всё администрирование Sightline — разбор жалоб на игроков и сообщений о проблемах, сведение названий техники, журнал действий, блокировки, права и аватарки — теперь делается только в отдельной панели администрации, не в программе.
- Для игроков ничего не меняется: всё остальное на месте. У администраторов на месте вкладки «Админка» теперь просто ничего нет.
- Программа больше не обращается к административным методам сервера ни при каких условиях: такие запросы отклоняются ещё до отправки. Сервер, со своей стороны, их от программы тоже больше не принимает.

## Установка

Скачайте `Sightline Setup 1.0.3.exe` и запустите. Установка поверх прежней версии сохраняет данные (`%APPDATA%\Sightline`).

**Сборка не подписана — SmartScreen предупредит** («неизвестный издатель»). Чтобы установить: «Подробнее» → «Выполнить в любом случае».

## Контрольные суммы (SHA-256)

```
<заполнить после сборки CI>  Sightline Setup 1.0.3.exe
```

Проверка в PowerShell: `Get-FileHash ".\Sightline Setup 1.0.3.exe" -Algorithm SHA256`
