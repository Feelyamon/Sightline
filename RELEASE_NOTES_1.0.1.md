# Sightline 1.0.1

## Двухфакторный вход

Двухфакторный вход: поддержка кода из приложения; для учёток с включённым вторым фактором нужна эта версия.

- После пароля программа спрашивает шесть цифр из приложения-аутентификатора (Google Authenticator или любое совместимое). Нет телефона — можно ввести один из резервных кодов.
- Учёткам, которым второй фактор обязателен (администрация), программа предлагает настроить его прямо в окне входа: QR-код (рисуется на месте, никуда не отправляется), секрет текстом для ручного ввода, поле для кода. После включения показываются восемь резервных кодов — их можно скопировать или сохранить в файл; дальше программа пускает только после отметки «Я сохранил».
- Включить или выключить второй фактор для обычной учётки можно в учётной записи на сайте feelyamon.ru.

Версия 1.0.0 на запрос кода покажет непонятную ошибку — если второй фактор у вас включён, обновитесь до 1.0.1.

## Установка

Скачайте `Sightline Setup 1.0.1.exe` и запустите. Установка поверх 1.0.0 сохраняет данные (`%APPDATA%\Sightline`).

**Сборка не подписана — SmartScreen предупредит** («неизвестный издатель»). Чтобы установить: «Подробнее» → «Выполнить в любом случае».

## Контрольные суммы (SHA-256)

```
<заполнить после сборки CI>  Sightline Setup 1.0.1.exe
```

Проверка в PowerShell: `Get-FileHash ".\Sightline Setup 1.0.1.exe" -Algorithm SHA256`
