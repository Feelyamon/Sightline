# Sightline 1.0.0

Companion-приложение для War Thunder для Windows. Читает кил-фид из локального веб-сервера самой игры (`http://127.0.0.1:8111`), показывает, кто на какой технике воюет прямо сейчас, и копит локальную историю боёв и игроков. Учётная запись, друзья и синхронизация работают через https://sightline.feelyamon.ru.

> Проект не аффилирован с Gaijin Entertainment. Приложение работает только с локальным API, который игра предоставляет сама, и ничего в клиенте игры не меняет.

## Установка

Скачайте `Sightline Setup 1.0.0.exe` и запустите. Установщик позволяет выбрать папку и создаёт ярлык на рабочем столе. Данные хранятся в `%APPDATA%\Sightline` и при удалении программы не стираются.

**Сборка не подписана — SmartScreen предупредит** («неизвестный издатель»). Чтобы установить: «Подробнее» → «Выполнить в любом случае».
