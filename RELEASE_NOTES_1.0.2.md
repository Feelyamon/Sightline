# Sightline 1.0.2

## Бои без входа

- При запуске без входа в аккаунт программа предупреждает: такие бои не проверяются и в статистику аккаунта не идут. Кнопка «Да, я понимаю» становится активной через 5 секунд, «Вход / регистрация» — сразу. После входа окно не появляется; после выхода — один раз.
- Бой, записанный без входа, остаётся только на этом компьютере — навсегда. В списке боёв он помечен «без входа». Вход в аккаунт не выгружает накопленную историю: на сервер уходят только бои, начатые после входа, по одному, по мере окончания.

## Пароль

- «Сменить пароль» в карточке аккаунта и «Забыли пароль?» на экране входа открывают сайт feelyamon.ru в браузере.

## Исправления

- Окно больше не прячется при переходе из ангара в бой с настройкой «Спрятать программу, когда игра закрыта»: на загрузке карты игра молчит по 10–20 секунд, и программа принимала это за выход из игры. Теперь игра считается закрытой после 20 секунд тишины, а окно прячется ещё через 10, если игра так и не вернулась.
- Значок программы: в установленной версии в части мест Windows (диспетчер задач, автозагрузка, списки программ) вместо него показывалось стандартное «окошко». Значок теперь содержит все размеры, включая установщик и деинсталлятор.
- Резервные копии базы боёв (`battles.db.*.bak`) делаются целиком, вместе с журналом базы. Раньше копия могла оказаться устаревшей или нечитаемой.
- Повреждённая база боёв больше не роняет программу и не теряется: файл откладывается рядом (`battles.db.corrupt-…`), в новую базу переносится всё, что читается, и программа сообщает об этом.

## Установка

Скачайте `Sightline Setup 1.0.2.exe` и запустите. Установка поверх прежней версии сохраняет данные (`%APPDATA%\Sightline`).

**Сборка не подписана — SmartScreen предупредит** («неизвестный издатель»). Чтобы установить: «Подробнее» → «Выполнить в любом случае».

## Контрольные суммы (SHA-256)

```
<заполнить после сборки CI>  Sightline Setup 1.0.2.exe
```

Проверка в PowerShell: `Get-FileHash ".\Sightline Setup 1.0.2.exe" -Algorithm SHA256`
